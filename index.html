再点火 Saitenka

Learn Japanese from the video you're watching — FSRS subtitle coloring, hover→multi-dict tooltip, one-key Anki mining, drawn inside mpv.

Install

macOS / Linux:

curl --proto '=https' --tlsv1.2 -LsSf https://serjflint.github.io/saitenka/install.sh | sh

Windows (PowerShell):

powershell -ExecutionPolicy ByPass -c "irm https://serjflint.github.io/saitenka/install.ps1 | iex"

Or from PyPI: uv tool install "saitenka[full]"

Full documentation → saitenka.readthedocs.io · Source → github.com/serjflint/saitenka

These install scripts are published from install/ in the repo.
